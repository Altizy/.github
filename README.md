# Altizy · Public profile

This repository contains the public profile and visual identity used on the [Altizy GitHub organization](https://github.com/Altizy).

- [Organization profile](profile/README.md) — an introduction to Altizy in English and French.
- [Profile assets](profile/assets/) — the Altizy logo in light- and dark-background variants.

Altizy is a pilot-theory learning project focused on PPL(A) and LAPL(A) preparation, with subject-based practice, detailed explanations, mock exams, and progress tracking.
